苡晴 × HUNTR/X 英語冒險｜免費版

這是一個純靜態網頁 App，不需要付費 AI API。
特色：
- 三個角色：RUMI / MIRA / ZOEY
- 每句英文控制在 5 個英文單字以內
- 成人按「開始」才開始活動
- iPhone 瀏覽器可朗讀英文
- 若 Safari 支援，可用麥克風做簡單語音辨識
- 三張角色照片由成人在手機上各設定一次，存在本機瀏覽器 localStorage
- 不需要把孩子的照片或個資上傳到伺服器

要放到 iPhone 主畫面：
1. 先把這個資料夾放到免費 HTTPS 主機（例如 GitHub Pages）。
2. 用 Safari 打開網址。
3. 點「分享」→「加入主畫面」。

注意：
- 這個版本不接 AI，因此不會像 ChatGPT 那樣自由理解所有中文/英文回答。
- 優點是零月費、反應快、角色圖片可以一直留在畫面上。
